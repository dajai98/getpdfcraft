# Internal compression evidence collection

Publication status: INTERNAL - NOT READY FOR PUBLICATION. This is not a public Lab or a completed benchmark.

The nine historical inputs, eight outputs, nine inspections, historical README and data/lab/compression.json are immutable. Their hashes are registered in data/lab/manifest.json. legacy-collector.cjs is the exact historical source snapshot, retained for hash verification, not an executable entry point. Historical tests resolve its recorded source hash to this snapshot; all other historical checks remain.

Run from the repository root: node scripts/lab/collect-compression.cjs [--run-id ID]. Without an ID, a UTC timestamp plus UUID is used. Every invocation exclusively reserves tests/evidence/compression/runs/ID. Existing IDs, unsafe IDs and existing artifact names fail; even failed/incomplete runs cannot be reused. No historical evidence or Lab-wide index is overwritten. A failed run has failure.json; a completed run has manifest.json. COMPLETE means collection finished, not that all operations succeeded or that the study is complete.

After collection, review and explicitly register the new manifest path/hash in data/lab/manifest.json. Do not replace previous run entries. The collector does not silently update that index. Run node tests/compression-evidence.test.cjs. Its new run checks independently reparse inputs/outputs, verify fields, metadata/text/geometry, hashes and arithmetic, and test overwrite refusal in an isolated temporary directory.

Index validation is enforced before run inspection: activeRunId must resolve to exactly one eligible COLLECTED registration with a completed, hash-verified manifest and valid artifacts. Every run directory must be registered and every registered directory must exist. Unregistered directories (including partial runs), failure markers, incomplete manifests, duplicate IDs and malformed references fail validation explicitly; they are never silently skipped. Preserve partial artifacts for review rather than deleting them to make validation pass. The historical registration remains required. Run node tests/compression-index.test.cjs for in-memory negative cases, including the audit's removed-registration reproduction. Validation does not write the index or evidence.

Each run snapshots its collector and records source HEAD/hashes, local library versions, environment, fixture provenance, input/output/inspection hashes, raw parser results, UI errors, warnings and measurements. These files are internal and not imported by application routes. No clock is mocked; modification metadata can change output bytes/hashes between runs. Synthetic unencrypted inputs reproduce exactly; encrypted inputs use random salt and must be retained rather than expected to regenerate byte-identically.

Additional fixture: encrypted-input is qpdf-wasm AES-256 encryption of the synthetic text fixture, generated using installed local WASM. The passwords in the generator are public synthetic test credentials, never user passwords. Compress must reject it. No photographs, actual scans or office exports were available with verified provenance in this collection; these remain NOT AVAILABLE / NOT TESTED. No private filesystem documents were used.

The Node harness compiles the actual Compress handler and hook. React scheduling, URLs, controls and downloads remain simulated. PDF.js parsing is independent of pdf-lib serialization but is not pixel rendering. Text extraction is not interactive selection; parsed form fields/widgets are not proof of appearance or editability. Signatures, links/bookmarks/attachments, visual quality and real-browser downloads remain NOT TESTED. No preservation, compatibility or universal savings claims are supported.

Run compression-20261015-hardening-01 is preserved but superseded because the publication-status em dash became a question mark during script creation. Its measurements remain genuine.
