It does not measure paraphrase similarity, prove Internet-wide originality, establish copyright clearance or certify overall quality. The manual matrix above addresses semantic overlap that an exact-match scan cannot.

The scan can be reproduced by reading each catalog route, extracting JSON string values for `text`, `body` and `a`, normalizing whitespace and grouping strings of at least 100 characters by distinct slug; documentation counts come from `sections[].paragraphs` and `faqs[].a`.
